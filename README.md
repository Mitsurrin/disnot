# Distortion 0.1.0 — Minecraft 1.21.1 / Fabric

Первый технический прототип мода Distortion.

## Что уже реализовано
- Скрытый показатель напряжения от 0 до 100.
- Напряжение растёт в темноте, при низком здоровье и голоде.
- В безопасных условиях напряжение постепенно снижается.
- Четыре стадии: инкубационная, ранняя, средняя и терминальная.
- На новых стадиях появляются сообщения и пещерный звук.
- На поздних стадиях периодически появляются эффекты Darkness, Nausea и Blindness.
- Команды `/distortion status` и `/distortion reset`.
- Значение хранится в command tags игрока, поэтому переживает перезаход в мир.

## Сборка
Нужен JDK 21 и Gradle. Открой папку проекта в IntelliJ IDEA как Gradle-проект,
дождись синхронизации, затем запусти задачу `build`.

Готовый JAR появится в `build/libs/`. Для игры положи JAR и Fabric API в папку `mods`.

## Важно
Это ранний прототип системы напряжения, а не финальная версия мода.
Пока нет моделей существ, монолита, специальных структур, полноценной системы
обращения искажения и отдельных звуковых файлов. Значения баланса будут меняться.
